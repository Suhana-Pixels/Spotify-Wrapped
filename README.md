# 🎵 Bollywood Spotify Wrapped Data Compiler

[![Java Version](https://shields.io)](#)
[![Domain](https://shields.io)](#)
[![GDG Selection](https://shields.io)](#)

An analytical Java simulation engine that models a music streaming platform's year-end data pipeline. Instead of running generic sample data, this engine processes real metadata blocks of iconic **Bollywood tracks, playback metrics, and artist signatures** to compile personalized user-facing profile summaries.

---

## 🚀 Core Features & Data Operations

*   **Linear Time Metric Synthesis:** Implements algorithmic product accumulation (`Play Count × Song Duration`) to calculate total app engagement down to the exact minute.
*   **Peak Anomaly Extraction (O(N) Space-Time Complexity):** Performs a single-pass linear search across parallel array structures to pinpoint consumption extremes (your absolute #1 anthem) without memory leaks.
*   **Desi Behavioral Classification Matrix:** Uses strict conditional evaluation limits to automatically assign programmatic user profile badges based on their annual listening density.

## 🏁 How To Execute Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```
3. **Compile the bytecode:**
   ```bash
   javac BollywoodWrapped.java
   ```
4. **Boot the simulation engine:**
   ```bash
   java BollywoodWrapped
   ```
